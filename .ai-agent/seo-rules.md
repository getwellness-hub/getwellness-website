# SEO Rules — Wellness, Love & Relationships

## 1. SEO Objective

Continuously improve organic search visibility while preserving
content quality, accuracy, user experience, and website stability.

SEO must never be treated as a reason to create low-quality content.

---

## 2. Every Page Audit

Check important HTML pages for:

- Unique title
- Useful meta description
- Canonical URL
- One clear H1
- Logical H2/H3 headings
- Descriptive URL
- Relevant internal links
- Useful image alt text
- Mobile usability
- Indexability
- Broken links

---

## 3. Search Intent

Before improving or creating an article:

1. Identify the user's likely search intent.
2. Understand the question the page should answer.
3. Make the content directly useful for that intent.
4. Avoid keyword stuffing.
5. Never write content only to target keywords.

---

## 4. Titles

Titles should:

- Clearly describe the page.
- Be natural and useful.
- Match the actual content.
- Avoid clickbait.
- Avoid unnecessary keyword repetition.

Do not change a working title without a clear reason.

---

## 5. Meta Descriptions

Meta descriptions should:

- Accurately summarize the page.
- Be unique where practical.
- Encourage useful clicks without misleading users.
- Match the actual search intent.

Never make false promises.

---

## 6. Internal Linking

Build a logical structure:

Homepage
→ Topic
→ Article
→ Related Article

Add links only when they are genuinely useful.

Prefer descriptive anchor text.

Never create irrelevant links just for SEO.

---

## 7. Sitemap

Check that important indexable pages are represented in sitemap.xml.

When a new article is published:

1. Verify the URL.
2. Add it to sitemap.xml if appropriate.
3. Verify that the URL is live.
4. Check for accidental duplicate URLs.

Never remove valid URLs from the sitemap without a reason.

---

## 8. Robots.txt

Check robots.txt for accidental blocking of important pages.

Never add rules that unintentionally prevent search engines
from accessing important website content.

---

## 9. Structured Data

Use structured data only when it accurately represents the page.

Never add fake:

- reviews
- ratings
- authors
- organizations
- events
- facts
- statistics

Validate structured data before publishing.

---

## 10. Content Quality

SEO improvements must prioritize:

- Accuracy
- Originality
- Usefulness
- Readability
- Clear organization
- Trustworthy sources
- Helpful internal links

Do not create thin pages simply to increase indexed page count.

---

## 11. Article Refresh

Existing articles should periodically be reviewed for:

- outdated information
- missing sections
- unclear explanations
- broken links
- outdated sources
- better internal linking
- improved readability

Only update an article when there is a meaningful improvement.

Preserve useful existing content.

---

## 12. New Article Rules

Before creating a new article:

1. Search the existing website for overlapping topics.
2. Avoid duplicate or near-duplicate articles.
3. Identify a genuine information gap.
4. Create a useful, focused article.
5. Add appropriate internal links.
6. Add SEO metadata.
7. Check the article before publication.

---

## 13. Search Console

When Search Console data is available, review:

- Queries
- Impressions
- Clicks
- CTR
- Average position
- Top pages
- Pages with increasing impressions
- Pages with declining performance

Use this information to identify improvement opportunities.

Do not make decisions from a single day's data alone.

---

## 14. Technical SEO Safety

Before publishing SEO changes:

- Check canonical URLs.
- Check internal links.
- Check sitemap.
- Check robots.txt.
- Check image paths.
- Check article URLs.
- Check mobile layout.
- Check that existing pages still work.

If a critical check fails:

STOP.

---

## 15. Protected Assets

Never modify protected image files.

Never rename existing working article URLs automatically.

Never change the website brand or domain as an SEO experiment.

---

## 16. No Guaranteed Rankings

Never claim that an SEO change will guarantee:

- Google ranking
- traffic
- indexing
- clicks
- revenue

Report observations and opportunities honestly.

---

## 17. Change Policy

Prefer small, measurable improvements.

Before making a significant SEO change:

1. Record the reason.
2. Record the affected pages.
3. Preserve the previous version.
4. Test the change.
5. Publish only after successful checks.

If no meaningful SEO improvement is identified:

DO NOTHING.

---

## 18. Core SEO Principle

Create the best useful page for the reader first.

Then make it easy for search engines to understand.

Quality over quantity.
Useful content over keyword stuffing.
Evidence over assumptions.
Stable website over unnecessary changes.
