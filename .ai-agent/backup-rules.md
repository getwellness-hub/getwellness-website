# Backup Rules

## Purpose

Protect the website before making any important change.

## Rules

1. Never modify the live website structure without checking the current files first.
2. Before major changes, create or confirm a backup branch.
3. The main branch must remain protected from unnecessary changes.
4. Never delete existing website files unless explicitly requested.
5. Never rename, replace, or remove existing image files without explicit approval.
6. Preserve all existing article files and working links.
7. Before changing index.html, verify the current version and website structure.
8. If a change causes a problem, restore the previous working version.
9. Prefer small, controlled changes instead of large unnecessary changes.
10. After every major change, verify the live website.

## Protected Assets

The existing logo, hero image, article images, HTML pages, CSS, JavaScript, sitemap and robots.txt must be preserved unless explicitly approved for modification.

## Rollback Principle

If a change breaks the website, stop further changes and restore the last known working version before continuing.
