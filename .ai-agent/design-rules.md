# Design Rules — Wellness, Love & Relationships

## 1. Design Objective

Continuously improve the website's visual quality, usability,
accessibility, readability, mobile experience, and professional appearance.

Design changes must provide real user value.

Do not change the design merely for the sake of making it look different.

---

## 2. Current Brand Identity

Preserve the established:

- Website name
- Brand identity
- Logo
- Existing visual assets
- Website purpose
- Professional educational character

Do not change branding automatically.

---

## 3. Protected Visual Assets

The existing logo, hero image, and protected article images
must never be:

- deleted
- renamed
- moved
- replaced
- cropped destructively
- modified automatically

unless explicit human approval is provided.

---

## 4. Mobile First

Every design improvement must consider mobile users first.

Check:

- navigation
- text size
- spacing
- buttons
- cards
- images
- article readability
- search
- forms
- horizontal scrolling

Avoid layouts that require unnecessary horizontal scrolling.

---

## 5. Desktop Experience

After mobile compatibility is confirmed, check desktop:

- content width
- whitespace
- alignment
- typography
- navigation
- cards
- image proportions
- section spacing

The desktop design should remain visually balanced.

---

## 6. Typography

Prioritize:

- readability
- appropriate font sizes
- clear hierarchy
- comfortable line height
- sufficient contrast
- consistent headings

Do not use decorative typography that reduces readability.

---

## 7. Layout

Maintain a clear visual hierarchy:

Header
↓
Hero
↓
Topics
↓
Guides
↓
Supporting information
↓
Contact/CTA
↓
Footer

Major structural changes require review.

---

## 8. Navigation

Navigation should be:

- clear
- predictable
- accessible
- consistent
- easy to use on mobile

Never remove an important working navigation link automatically.

---

## 9. Article Design

Article pages should prioritize reading.

Use:

- clear headings
- readable paragraphs
- adequate spacing
- useful lists
- highlighted important information where appropriate
- related guides
- clear navigation back to relevant topics

Avoid excessive visual decoration.

---

## 10. Cards

Article/topic cards should have:

- clear titles
- useful descriptions
- consistent spacing
- accessible links/buttons
- responsive layout

Do not create excessive cards simply to fill space.

---

## 11. Images

Images should:

- load correctly
- have useful alt text where appropriate
- maintain appropriate proportions
- not break the layout
- not reduce readability

Never replace protected images automatically.

---

## 12. Accessibility

Continuously check:

- color contrast
- keyboard navigation
- focus visibility
- alt text
- semantic HTML
- button/link clarity
- heading hierarchy
- readable text size

Accessibility improvements should be preferred when they do not negatively affect functionality.

---

## 13. Performance

Design changes should consider:

- page size
- image loading
- unnecessary scripts
- unnecessary CSS
- layout stability
- loading speed

Avoid adding heavy libraries or unnecessary assets for minor visual effects.

---

## 14. Responsive Testing

Before publishing a significant design change, check:

- small mobile
- standard mobile
- tablet
- desktop

If a change breaks an existing layout:

STOP and fix or rollback.

---

## 15. Visual Consistency

Maintain consistency across:

- homepage
- article pages
- contact page
- terms page
- navigation
- footer
- buttons
- cards
- headings

New pages should look like part of the same website.

---

## 16. Progressive Design Evolution

Improve the design gradually.

Prefer:

Small improvement
↓
Test
↓
Measure
↓
Keep or rollback
↓
Next improvement

Avoid frequent complete redesigns.

---

## 17. No Artificial Daily Changes

The agent must not change the design every day just because
the automation runs every day.

If there is no meaningful design improvement:

DO NOTHING.

---

## 18. Design Experiment Rules

For a significant experiment:

1. Preserve the previous version.
2. Define the purpose.
3. Identify the expected improvement.
4. Test on mobile and desktop.
5. Check accessibility.
6. Check page performance.
7. Compare against the previous version.
8. Keep only if the result is clearly useful.

---

## 19. User Experience Priority

Prioritize:

1. Clarity
2. Accessibility
3. Readability
4. Navigation
5. Performance
6. Visual polish

Do not sacrifice usability for visual effects.

---

## 20. Safety

Never automatically:

- delete design files
- replace the logo
- replace protected images
- change the brand
- change the domain
- remove important sections
- remove working navigation

Major changes require human approval.

---

## 21. Core Design Principle

Make the website feel more professional over time.

Do not chase trends blindly.

Use modern design principles when they improve the actual user experience.

Every design change must have a reason.
Every significant change must be tested.
Every failed change must be reversible.
